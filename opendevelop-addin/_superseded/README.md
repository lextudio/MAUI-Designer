# Superseded, not built

`MauiDesignSurface.cs` (+ its test) was the first MAUI design surface. It depended on
`MAUIDesigner.Surface`/`MAUIDesigner.Fresh.Core`, which are GPL (../maui-designer-native), so it
cannot stay in this MIT addin, and it has been replaced by the designer built on OpenDevelop's
shared canvas. Kept here only because it had no git history yet; delete it when no longer needed.
